# Conceitos fundamentais do Protheus 

## a. Qual é a função do AppServer?
É o servidor que lê e executa o código e faz a integração com o banco de dados.

## b. O que é o RPO?
É um arquivo único que contém todo o código fonte protheus já compilado e pronto para ser executado no appserver.

## c. Para que serve o Configurador (SIGACFG)?
É onde fazemos a configuração de dados, alterar propriedade dos campos, criação de novos campos, etc.

## d. Qual a diferença entre campo Real e campo Virtual no SX3?
Campo real: existe fisicamente no banco de dados e guarda informações digitadas na tabela. Campo virtual: não existe no banco de dados, apenas na tela, usa formulas ou buscas para mostrar dados temporários em tempo real.
